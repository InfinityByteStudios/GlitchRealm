Performance on Low-End Devices

Getting a steady frame rate out of an older laptop, a budget phone or a slow connection

← All guides

Browser games are lighter than installed games, but they are not free. A modern browser is a full rendering platform, and a game competes with every other tab, extension and background service on the machine. On a low-end device, that competition is what turns a smooth game into a slideshow.

This guide is ordered from the changes with the biggest effect to the smallest. Start at the top and stop when the game is playable.

1. Turn on hardware acceleration

Hardware acceleration lets the browser draw with your graphics processor instead of the CPU. It is the single most important setting for browser game performance, and it is sometimes switched off after a driver update or by a power-saving policy.

  • Chrome and Edge — Settings → System → “Use graphics acceleration when available”. Relaunch the browser after changing it.
  • Firefox — Settings → General → Performance → “Use hardware acceleration when available”.
  • Safari — hardware acceleration is on by default on macOS; there is no user-facing switch.

After enabling it, open chrome://gpu or about:support in Firefox and check that WebGL and canvas acceleration are listed as hardware accelerated rather than software only.

2. Close what you are not using

Every open tab holds memory and timers. A video tab, a chat app and a dozen background tabs can consume more CPU than the game. Close them before you play, especially anything that plays audio or video.

On Windows, check Task Manager for background processes using high CPU. On macOS, use Activity Monitor. On phones, close apps you are not using and restart the browser if it has been open for days.

3. Reduce the rendering workload

  • Play at 100% browser zoom. Any other zoom level forces the browser to rescale every frame.
  • Use a smaller window. Rendering fewer pixels is the most direct performance win. A game that stutters at fullscreen may run smoothly in a window.
  • Lower the display resolution on very old machines. A 4K panel driven by integrated graphics is a heavy load for any canvas game.
  • Disable animations in the operating system if the browser feels sluggish even outside games. Reduced motion also helps the site's own interface.
  • Turn off browser features you do not need while playing, such as picture-in-picture video or a second monitor running a video stream.

4. Check extensions and content blockers

Extensions run inside every page you open, and some of them rewrite or observe the page constantly. Ad blockers and privacy tools are usually fine, but aggressive script blockers, grammar checkers and screenshot tools can add measurable overhead.

Test with extensions disabled for the game's domain. If performance improves, re-enable them one at a time. Allowlisting glitchrealm.ca and the game's own domain is usually enough; you do not need to uninstall anything.

5. Improve the network side

Browser games load assets over the network. A slow first load is often bandwidth, while stutter during play is usually latency or packet loss.

  • Prefer a wired connection or a 5 GHz Wi-Fi band over a crowded 2.4 GHz network.
  • Pause downloads and video streams while playing online games.
  • Move closer to the router, or use a mesh node, if the signal is weak.
  • Disable VPNs for online games when you can. A VPN adds a hop and often increases latency.
  • Reload the page after a network drop. Some games recover badly from a brief disconnect and keep retrying stale requests.

6. Mobile-specific advice

Phones thermal-throttle. A game that runs well for five minutes and then stutters is usually hitting a temperature limit, not a memory leak. Remove the case if it traps heat, avoid charging while playing, and lower screen brightness.

Close background apps, disable battery saver for the browser, and keep the browser updated. On Android, Chrome's “Lite mode” and data-saving features can interfere with game assets; disable them for the game's domain. On iOS, low power mode reduces background activity and can affect frame pacing.

7. What not to do

  • Do not install “game booster” software. It rarely helps browser games and often adds background processes of its own.
  • Do not disable your antivirus to gain performance. The risk is not worth the few frames.
  • Do not use unofficial browser flags you do not understand. A flag that helps one site can break another, and the effect is usually temporary.
  • Do not judge a game by its first ten seconds. Shader compilation and asset streaming often settle after the first level.

8. When the device is simply too old

Some hardware cannot run modern WebGL games at a playable frame rate, and no setting changes that. Integrated graphics from before roughly 2015, phones with 2 GB of RAM and browsers that no longer receive updates are the usual limits. In that case, prefer games tagged as text-based, puzzle or incremental; they are designed to run on modest hardware.
